Code check, energy code and Manual J8

Contents

Three pages help with the permit: Code check (the mechanical and energy code items for the HVAC work, checked against the design where there are numbers), Energy code (the prescriptive envelope check, residential) and Manual J8 (the strict Manual J 8th Edition procedure and the ACCA approval work). The code data in the app is reviewed on a schedule; Options, Code data says when.

Everything on these pages is a design aid. The checks name the code section and say to verify the edition the jurisdiction adopted. They are not a review by the building official.

Run the code check

What it is for. See the code items that apply to the job's HVAC work, in plain words, with the design's own figures where the app has them, and mark the rest as you confirm them.

Where. The Code check page. Both editions; each edition has its own sections.

Steps.

  1. Pick where each unit is (for example Closet or interior room, Attic, Crawl space, Garage, Outdoors (packaged unit), Wall or ceiling (ductless head)). The location picks the access, clearance and condensate items.
  2. Pick Show: Everything, What applies or Open items.
  3. Read each row: Section, Requirement, This design and Status.
  4. On each row, pick a Mark: Automatic (the app's own status), Confirmed, Open or Does not apply.
  5. Press Preview checklist or Checklist (PDF). Add code notes to the plan set puts the notes on the plan set. Pick permit jurisdiction goes to Design conditions.

What you get. Counts at the top: Meets, Does not meet, Check, Open, Confirmed and Does not apply. With no jurisdiction picked, the items use the 2021 IRC and IECC numbering and say so.

Limits. The page says it: confirm against the adopted edition and local amendments. A "Meets" is the app's reading of the design, not an approval.

Residential code check sections

Where. Code check, residential edition.

  • Sizing, energy and ventilation (IRC M1401, M1505, M1601, IECC R403): the load calculation (Manual J), cooling equipment sizing and latent capacity (Manual S, by the limits in Equipment), design airflow against equipment airflow, duct insulation (IECC R403.3.1), duct sealing and the leakage test (IECC R403.3.2 to R403.3.5), and whole-house mechanical ventilation (IRC M1505.4; IECC R403.6). Ventilation follows the job's IRC edition: 2018, Table M1505.4.3(1) or Equation 15-1 (either meets the code); 2021 and 2024, Equation 15-1.
  • Exhaust (IRC M1502, M1503, M1504, M1505): bath and kitchen exhaust rates, range hoods and makeup air over 400 cfm, clothes dryer exhaust, and exhaust terminations and outdoor air intakes.
  • Ducts and returns (IRC M1601, M1602, R302.5): ducts sized by Manual D (passes only when every system's static is within its rating and no duct is over its velocity limit), building cavities, return air locations (M1602.2), ducts in a garage, joints and seams, flex listed and supported, duct insulation fire ratings.
  • Equipment access and location (IRC M1305, M1307): working space, closets, attic and crawl space installations, units in a garage, outdoor units, listed equipment.
  • Condensate (IRC M1411): overflow protection, drain size, slope and maintenance, condensate pumps.
  • Refrigerant, Fuel gas and Electrical for HVAC.

Florida checks (residential)

Where. Code check and the design checks, when the permit jurisdiction is Florida. Residential edition.

  • Ventilation maximum. The Florida Building Code, Energy Conservation, 8th edition (2023), R403.6.2 item 1, makes the ASHRAE 62.2 rates the maximum. A whole-house ventilation rate above 0.03 x floor area + 7.5 x (bedrooms + 1) is flagged with the numbers.
  • Air handler in the attic. FBC-EC 2023 R403.3.6: not allowed on the prescriptive path (R402). On the performance path (R405) it needs four conditions; tick them on the unit in the Florida: air handler in the attic box. The check says how many of the four are ticked.

Washington and Oregon checks

What it is for. Washington and Oregon jobs get their own code sections and limits in the permit checklist, the Code check page, the permit report, the energy code envelope check and the field test targets.

Where. Pick the state on Design conditions, Permit jurisdiction. Residential edition. (Commercial: see Commercial.)

What it covers.

  • Washington, 2021 WSEC-R (with the 2021 IRC and IMC and Washington amendments), in effect since March 15, 2024: design temperatures, Manual J and S sizing, heat pump supplemental heat lockout, thermostats, duct insulation, ducts in conditioned space, sealing and cavities, duct leakage limits, the blower door limit, ventilation, fan efficacy and airflow testing, and the R406 credits the app can see.
  • Washington, 2024 WSEC-R (proposed): tick Check against the 2024 WSEC-R. It checks against the proposed text, which takes effect May 3, 2027.
  • Oregon, 2026 ORSC (2024 IRC base), effective October 1, 2026 and mandatory April 1, 2027, and the 2023 ORSC for permits applied for through March 31, 2027.
  • Seattle and Portland: each row says how the city's rules relate to the state's.

Limits. Proposed text can change before it takes effect. Confirm the edition with the building department.

Commercial code check sections

Where. Code check, commercial edition.

  • Ventilation and outdoor air: outdoor air by the ventilation rate procedure (IMC 403.1; ASHRAE 62.1), occupancy categories, multiple-zone system ventilation efficiency, MERV 8 filters ahead of cooling coils, air that may not be recirculated, dehumidification, intake location.
  • Exhaust, Duct systems, Fire and smoke protection, Equipment, access, support and condensate, Refrigeration, Fuel gas, Energy code, Commissioning, balancing and documents, Electrical for HVAC and Commercial kitchen exhaust.
  • The new checks (IMC 2021 602.2, 606.2.1, 607.5.5; IBC 2021 1023.5 and 1023.6) are described in Commercial.

The energy code envelope check (residential)

What it is for. Check the house against the energy code's prescriptive envelope tables: each component's U-factor against the table, or the whole house's UA against the code UA. The areas and U-factors come from the load calculation.

Where. The Energy code page, card Energy code envelope check. Residential edition.

Steps.

  1. Pick the Code: from the permit jurisdiction, or 2012 / 2015, 2018, 2021 or 2024 IECC, Florida 8th Edition (2023), California Title 24 (2025), Washington 2021 WSEC-R or 2024 (proposed), Oregon 2026 ORSC or 2023 ORSC (phase-in).
  2. Pick the Climate zone (or set it from Design conditions, Permit jurisdiction).
  3. Press Preview worksheet, Worksheet (PDF) or CSV.

Limits. The page says it: this is a design check. The permit form comes from the state's approved energy compliance program or, in California, the CEC-approved software.

Keep the code data current

What it is for. Know when the code editions built into this copy were last reviewed, and whether a newer review is out.

Where. Options, card Code data. Both editions.

What you get. The date the mechanical and energy code data was last reviewed, when the next review is due (every 6 months), when it last checked for updates, and Check for code updates. The check also runs by itself when the last one is more than 6 months old, and speaks only when there is something to do: newer code data, or an overdue review.

Limits. A building department can adopt or amend a code at any time. The edition in effect on the permit application date governs: confirm it with the building department. The check needs internet.

Manual J8 mode

What it is for. Calculate with the strict Manual J 8th Edition procedure, and track what ACCA approval needs.

Where. The Manual J8 page. The full page is in the residential edition; the commercial edition shows the mode and readiness cards. A shortcut, Strict Manual J 8th Edition mode, is in Options, Load calculation.

Steps.

  1. Tick Calculate with the strict Manual J 8th Edition procedure.
  2. Check the Elevation (blank = location). The line under it gives the altitude correction factor and the daily range class.
  3. Pick the Infiltration source: Table 5A by tightness (with the Construction tightness), Blower door test (ACH50 ÷ n), or Entered ACH (not MJ8).
  4. Pick the Duct loads source: Table 7 factors or Aerion calculation from the drawn ducts.
  5. Pick the Blower heat source: Estimate from fan power (with the Fan power, W/cfm) or Entered from the blower data.
  6. In Table 4A construction numbers, assign construction numbers once a data pack with Table 4A is loaded.

What you get. Strict mode switches to the Manual J8 air factors (1.1 x ACF sensible, 0.68 x ACF latent), Table 5A infiltration, Table 7 duct factors, Table 4A construction numbers, the AED test and blower heat, as the card says. Each part uses your ACCA data pack when it is loaded, otherwise Aerion's estimate. The Form J1 line items card shows each room's components with their construction number, area, HTM and load.

Limits. Until a data pack is loaded, the Manual J8 numbers are Aerion's estimates of ACCA's tables. When the equipment data is not discounted for blower heat, Manual J's default is 500 W, 1,707 BTU/h (ACCA Instructor's Lesson Plan p. 13); a design check gives both that and the app's estimate.

ACCA data pack, test cases and review reports

Where. The Manual J8 page, cards Certification readiness, ACCA data pack, Validation test cases, ACCA review reports and One change at a time. Residential edition (the first three are in both).

What it is for. Get ready for ACCA's software review. The card says what approval needs: a license to use Manual J (the "Powered by Manual J" agreement), ACCA's tables in the engine, and matching ACCA's reference houses within their tolerance. The page tracks all three.

Steps.

  1. Certification readiness shows the checks met, whether a data pack is loaded and the test cases, with a table of each requirement, its Manual J8 rule and this project's state.
  2. ACCA data pack: Download template, fill it from your licensed ACCA tables, then Import data pack. Export pack and Remove pack are there too. The pack is stored in this browser only and is never published with the app.
  3. Validation test cases: enter each ACCA reference house as a project, Add current project, then type ACCA's expected results. Run all compares Aerion's Manual J8 results line by line. Import cases, Export cases and Export certification packet.
  4. ACCA review reports: Form J1 + Worksheet A (PDF), Plan Review Form (PDF), Defaults and methods (PDF) and J1 line items (CSV), each with a preview. Turn on Manual J8 mode and load the data pack first so they use ACCA's tables.
  5. One change at a time: pick the Base house, then add the single changes ACCA asks for (orientation turned 90°, 180° or 270°, window U-factor, SHGC, shading, overhang, insulation, tightness and others) or Add a custom change. Each run uses Manual J8 mode on a copy of the base house and is compared with it.

Limits. The page says it: nothing here is an ACCA approval. ACCA approval of Aerion is in progress; until it is granted, a building department that requires an ACCA-approved program needs one (see Reports and letters for the hand-off to another load program).
