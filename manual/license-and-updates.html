License and updates

Contents

This page covers buying and activating a license, moving it to another computer, keeping Aerion up to date, and the desktop app. Everything here is in both editions.

Plans and prices

Aerion is sold by subscription, monthly or yearly. The current plans:

There is a 14-day free trial. During the trial, PDFs carry a TRIAL watermark and CSV and DXF exports are off. What each plan includes is on the pricing page, which Buy a license opens.

ACCA approval of Aerion is in progress. It is not an ACCA-approved program yet (see Code check, energy code and Manual J8).

Activate your license

What it is for. A customer copy locks exports, printing and saving until a license key is activated.

Where. Options, card License. Buy a license is also in the Not activated bar. Both editions.

Steps.

  1. If you have no license yet, press Buy a license. It opens the Aerion pricing page, where checkout starts. After checkout the license key shows on screen.
  2. Type the Purchase email and the License key, or press Load key file.
  3. Press Activate. With no email, the message asks for the email used for the purchase.

What you get. The card shows the plan (with "free trial", "monthly subscription" or "yearly subscription"), and when the key runs to.

This computer. The card shows this computer's machine code. Copy copies it. In the desktop app the code is worked out once and kept, so it stays the same on every start, whatever network adapters are connected. A copy of the app folder on another computer does not carry it.

Renewal. The key renews itself after each monthly or yearly payment, as long as the computer goes online now and then (at least monthly, or every 60 days on a yearly plan). Offline, the current key works until its date. When a trial turns into a paid plan, the key renews itself.

Move to another computer. Use Move to another computer first, so the seat is freed. Then activate on the new computer.

Team accounts. To join a business account, enter your email and the invite code (TEAM-…) the owner sent you, here in License (see Business, clients and team).

Updates

Where. Options, card Updates, and in the desktop app the update notice and Help, Check for updates…. Both editions.

In a browser. Reload the page to get the current version. The card says so.

In the desktop app.

  • The app checks for a new version by itself. The Updates card shows the version installed, the latest version found and its date, when it last checked, what changed, Check for updates, Restart and update (or Download), and Update automatically.
  • Update automatically is on to start with: new versions download by themselves and install when Aerion is closed. Off: Aerion still checks and says a version is available, and downloads it only when you ask.
  • While a version downloads, a notice in the window shows the progress. When it is ready: Restart and update or Later. Later hides the notice until the next start; the update then installs when Aerion is closed.
  • What's new since your version. A copy several versions behind (say 1.5.50, updating to 1.5.57) shows "What's new since 1.5.50" in the notice, in the Updates card and in the Help menu's dialog: every version's notes from the one installed up to the new one, newest first, in a short list that scrolls when it is long. A copy one version behind shows the new version's notes alone.

Limits. Each download's size and checksum are checked before it runs; a file that does not match is deleted.

The desktop app

What it is for. Aerion as a Windows program, with normal file windows, a menu, and project files that open with a double-click.

What it adds.

  • Save and Open use the Windows file windows. Every PDF, CSV, DXF and project save goes to a file picker, with no browser download prompt.
  • A menu: File (New project, Open project…, Save project…, Plan set (PDF), Permit report (PDF)), Edit, View (zoom and full screen), Graphics (Graphics status…) and Help (Check for updates…, About, Uninstall Aerion HVAC Design Studio…).
  • Aerion project files open in the app when you double-click them.
  • Import DWG on the Layout works when a DWG converter is installed (ODA File Converter, which is free, or LibreDWG dwg2dxf).
  • The BIM models page's Your models card and the add-in jobs folders (see BIM models and plan set to 3D).
  • Aerion AI on this PC goes through the app itself, which sends it to this computer only.

Safety. The app's windows show only Aerion's own page. A web or mail link opens in your browser or mail program; any other address is refused. New windows are only the pop-out panels and PDF previews. The app's own functions (save, open, DWG, the add-in jobs, updates, AI on this PC) answer only Aerion's page and its pop-outs.

Speed. The Layout's 3D view and the airflow simulation use the graphics card when they can. Graphics status… in the menu shows what the app is using.
