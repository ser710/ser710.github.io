License and updates

Contents

Activate your license

What it is for. A customer copy locks exports, printing and saving until a license key is activated.

Where. The Options page, the License card. Both editions.

Steps.

  1. If you have no license yet, press Buy a license. It opens the Aerion pricing page. After checkout the key shows on screen.
  2. Type the Purchase email and the License key, or press Load key file.
  3. Press Activate. With no email, the message asks for the email used for the purchase.

This computer. The card shows this computer's machine code. Copy copies it. In the desktop app the code is worked out once and kept, so it stays the same on every start, whatever network adapters are connected. A copy of the app folder on another computer does not carry it.

Renewal. The key renews itself after each monthly or yearly payment as long as the computer goes online now and then (at least monthly, or every 60 days on a yearly plan). Offline, the current key works until its date.

Move to another computer. Use Move to another computer first, so the seat is freed.

Updates

Where. The Options page, the Updates card.

  • In a browser, reload the page to get the current version. The card says so.
  • The desktop app updates itself. The card shows the version installed, the new version and its date, when it last checked, what changed, Check for updates, Restart and update (or Download), and Update automatically.
  • Update automatically is on to start with: new versions download by themselves and install when Aerion is closed. Off: Aerion still checks and says a version is available, and downloads it only when asked.
  • While a version downloads, a notice in the window shows the progress. When it is ready: Restart and update or Later.
  • Help > Check for updates checks now.

Limits. Each download's size and checksum are checked before it runs; a file that does not match is deleted. The update notice is being changed; this section will be updated when that work ships.
