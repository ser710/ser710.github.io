Reports and letters

Contents

All of these are on the Reports page. Each PDF has a Preview button: the preview shows each page as it will print, and you print or download from there.

Plan set, permit report and other exports

Where. The Reports page, the Print preview card.

Steps.

  1. Press Preview plan set or, in the residential edition, Preview permit report.
  2. Check the pages, then print or download from the preview.

What is in the card.

  • Plan set (PDF).
  • Residential: Permit report: Manual J/S/D + Title 24 (PDF). Commercial: Commercial load report (PDF).
  • Fabrication isometrics (PDF), Preview fab isos.
  • Commissioning sheet (PDF), Preview commissioning sheet.
  • Files: Project file (.json), Room loads (.csv), Duct schedule (.csv), Sheet metal shop list (.csv), Duct layout for CAD (DXF), Send to the modeling program (3D).
  • For entering the job in a load program: Load program hand-off (ZIP), Plan for tracing, this floor (DXF), Load takeoff (PDF) and (spreadsheet), Floor plans to upload (PDF) and (PNG), Wall-by-wall entry (PDF) and (spreadsheet). The card Using a load program for the permit report (step by step) explains the steps.
  • Plan set → Markup, Permit report → Markup (residential), Fab isos → Markup: open the finished PDF in Plans & markup for clouds, callouts and stamps before it goes out.

Limits. A building department decides what it accepts. The designer of record checks and signs the design.

Scope of work letter

What it is for. A letter written from the project: the client, the equipment, the ducts, ventilation, controls, start-up, and what is and is not included.

Where. The Reports page, the Scope of work letter card. Both editions.

Steps.

  1. Read and edit the letter in the card.
  2. Press Preview to see it as it prints, or Save as PDF, or Copy text.
  3. Press Rebuild from the design to write it again from the project after a change.

Operating cost and proposal (residential)

Where. The Reports page, the Operating cost and proposal card. Residential edition.

Steps.

  1. Pick the Method: 8,760-hour simulation or Degree days (quick).
  2. Set the Electric rate and Gas rate, or press State average rates.
  3. Pick the Heating fuel. Edit Included, Not included and Terms.
  4. Press Preview proposal, then Proposal (PDF). Preview rebate data sheet and Rebate data sheet (PDF) make the rebate sheet.

Limits. The 8,760-hour run uses a synthetic year fitted to the weather station's normals; the card shows them. State average rates are averages, not your utility's rates.

Revisions and change orders

Where. The Reports page, the Revisions and change orders card. Both editions.

Steps. Type a Description and press Issue Rev 0. The message says the revision was issued and that changes from then on are compared with it. Tick Revision block on the sheets and Cloud the latest changes on the plan set to show them on the plan set.

Submittal package

Where. The Reports page, the Submittal package card. Both editions.

Steps. Fill in Submittal # and Submitted to, tick Include the load summary if you want it, and use Attach PDF or photo to add the maker's cut sheet to each item. Press Preview front pages, then Submittal package (PDF).

What you get. The card says: a cover, index, equipment list, AHRI match and load summary, then each item's cut sheet stamped with its item number. Attachments stay in this browser.

Field tests (residential) and test and balance (commercial)

  • Residential: Field tests and compliance. Enter the results as the tests are done (blower door, duct leakage, airflow, static, charge check). Each is compared with the energy code targets picked in Targets from. Preview test report, Field test report (PDF), Preview energy certificate, Energy certificate, IECC R401.3 (PDF).
  • Commercial: Test and balance. Enter the readings from the test and balance report; each is compared with the design airflow, outdoor air and static. Preview TAB summary, TAB summary (PDF).
