This page covers what is different in the commercial edition. The tools in the other pages of this manual work in both editions unless they say otherwise.

Plenum returns in the airflow simulation and room pressure

What it is for. On many commercial floors the return air goes up through ceiling return grilles into the ceiling plenum, with no duct behind the grille. The airflow simulation and the room pressure check take these grilles as returns.

Where.

  • The Layout page, the Airflow button (Airflow simulation).
  • The Load calculator page, the room editor, the Room pressure, door shut section.

What you get.

  • Airflow simulation. Each ceiling return grille with no duct behind it takes its share of the floor's supply that the ducted returns do not take back, shared by face area. Return air moves to these grilles in the simulation.
  • Room pressure. A room with one of these grilles sends its air up into the plenum, not under the door, so it is not flagged for door-shut pressure.

Limits.

  • This is only in the simulation and the room pressure check. The grilles' own airflow, the return sizing and the schedules do not change.
  • Floors with ducted returns work as before.
  • A room with no return grille drawn in it still pushes its supply under the door. Where a room has a ceiling return grille, draw it in that room.

Where the commercial edition differs (for the features in this manual)

  • Snip, Rotate, duct labels, Tidy labels, the plan reader and Build rooms work the same in both editions.
  • Aerion AI on this PC. In a customer copy of either edition, the card is there only when the license has the AI add-on.
