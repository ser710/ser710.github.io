Aerion AI on this PC: the model name

What it is for. Aerion AI can send its questions to an AI service running on your own computer instead of the online AI service. This section covers the model name.

Where. The Options page, the Aerion AI on this PC card. In a customer copy the card is there only when the license has the AI add-on.

Steps.

  1. Tick Use the AI on this PC for Aerion AI.
  2. In Model name, type the name of the model on this computer.
  3. Press Test to see what it answers.

Model names with a space. You can type the name the way it is said. Spaces are sent as dashes: "chicken scoot" is sent as chicken-scoot.

When the name is refused. If the AI service on this computer still refuses the name, the message says to type the name the way the computer's list of models shows it. In a command window, ollama list shows that list.

What you get. Questions go to the AI service on this computer only (127.0.0.1, port 11434): no key, no internet.

Limits. The card itself says it: a model that fits on a desktop is weaker than the online AI service. Use it for wording and explaining, and check any number it gives.
