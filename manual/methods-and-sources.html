Methods, sources and defaults

Contents

This page collects how Aerion works things out, where each rule comes from, and which values are defaults for you to replace. It is a reference: each feature's own page says more. The full list of public sources the app was checked against is kept in the app's repository as docs/load-calc-sources.md. Where a value could not be found in a public source, the app labels it a default and this page says so.

The designer of record checks the method and every input for the job.

Defaults in the residential loads. The duct leakage percents, the radiant barrier cut (40%), the attic design temperature a new project starts with (125°F), the attic temperature from the roof color (outdoor + 32°F x absorptance), the vented crawl space temperatures (halfway between indoor and outdoor for cooling, 30% of the way from outdoor to indoor for heating: no public source gives one figure), the door U-factor (the project's exterior door, 0.35 in a new project; IECC 2021 Table R303.1.3(2) gives 0.50 for an unrated wood door and 0.60 for insulated metal), the glass share used before windows are drawn, the appliance gains, and the split of the ventilation load between several systems by floor area (Manual J gives no rule for that). Replace them with the job's figures.

Air filters

Each filter's drop is read from its own published data: straight-line on log-log axes between published points, the power law through the nearest two points beyond them, and the median exponent for a filter with one point. The face velocity limits used to pick a comparison size (300, 350 and 450 fpm by depth) are the app's way to compare, not a rating. The Sources and method card on the Equipment page lists every source.

Codes

Each code check names its section: the IRC, IECC, IMC, IBC, the Florida Building Code, Energy Conservation (8th edition, 2023), the Washington and Oregon codes, and the NEC sections on the Controls page. The code data in the app is reviewed every 6 months (Options, Code data). A building department can adopt or amend a code at any time; the edition in effect on the permit application date governs.

Drawing defaults

These shape the drawing only and change no number: the 4 ft cut height and units guess for a 3D model underlay, the high wall unit's drawn size (32 x 9 x 12 in., mounted 7 ft to the bottom), the schematic framing (16 in. on center, 6/12 roof pitch, lumber sizes and fallback heights), and the 1 in. clearance each side of a wall opening.
