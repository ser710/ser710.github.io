Files from and to other programs

Aerion opens the files you get from architects, engineers and suppliers, and saves files the other programs on the job open. Everything happens inside Aerion: there is nothing to download or set up, in the desktop app or in a web browser.

Open a file from another program

Press Open file at the top (beside Open), or drop the file anywhere on Aerion. Aerion sees what kind of file it is and opens it in the right place.

An .aerion file written by Project file in a folder (see Saving) opens with Open at the top, not with Open file or by dropping it.

Files Aerion cannot read, and what to do:

  • SketchUp's own .skp file: only SketchUp's program library reads it, and it cannot run in Aerion. In SketchUp use File > Export > 3D Model > COLLADA (.dae).
  • Revit .rvt: in Revit export IFC (or use the Aerion add-in).
  • DWF or DWFx: save the drawing as DWG, DXF or PDF.
  • FBX or 3DS: export GLB, OBJ, DAE or STL.
  • TIFF scans: save them as PDF or PNG.

After a gbXML opens, check each room's wall, ceiling and floor construction: gbXML carries the shape and the openings, and Aerion's own construction choices are used until you change them.

The CAD layers: A-WALL (outside walls), A-WALL-INT, A-ROOM (room outlines), A-ROOM-NAME, A-DOOR, A-GLAZ, A-ANNO-DIMS, A-ANNO, M-SUPPLY and M-RETURN with the system tag (for example M-SUPPLY-FAU-1), M-REGISTER, M-EQUIP, M-DUCT-TEXT.

The IFC model has the floors, the rooms as spaces with their loads and airflow, walls with their doors and windows, floor slabs, the ducts and fittings at their sizes on their supply and return systems, every register and grille, and the air handlers. Send to the modeling program still builds the ducts as native Revit ducts through the Aerion add-in.

Wall thickness (6 in outside, 4.5 in inside), window head height (6 ft 8 in) and floor depth (10 in) in these files are drawing defaults, not taken from the design. Change them in the other program when they matter there.
