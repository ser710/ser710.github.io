Saving: automatic saving, project files and backups

What it is for. Choose when Aerion saves your work, keep a project file in a folder without saving it by hand each time, and keep earlier versions to go back to.

Where. Options > Saving. Both editions. The settings are kept on this computer (each computer and browser has its own).

If you never open this card, nothing changes: every change is saved as you work, as before.

Save automatically

Pick one:

  • Every change (as now): the default. Each change is saved on this computer half a second after you make it.
  • Every 1 minute, Every 5 minutes or Every 10 minutes: changes are saved on that timer.
  • Off (save with the Save button or Ctrl+S): nothing is saved until you save it.

When saving is not on every change:

  • The top bar says Unsaved changes and shows a Save changes button. Ctrl+S saves too. (With saving on every change, Ctrl+S does what it did before: in the desktop app it opens the save window for a project file.)
  • Revert to last save on the card puts the project back as it was when you last saved it.
  • Closing the window or the app with unsaved changes asks first. Opening, starting or duplicating another project, or opening a file, asks too: OK saves the changes and goes on, Cancel stays on the project.
  • Unsaved work is also kept in a recovery copy on this computer. If Aerion closes before you save (a crash, a power cut), the next start shows Unsaved changes found with Restore the changes and Discard them. Restored changes are not saved yet: press Save changes or Ctrl+S to keep them.

Save as a copy and Save project file now

  • Save as a copy makes a new project from the work as it is now and switches to it. With saving on a timer or off, the original stays as it was last saved.
  • Save project file now writes the project file to the folder below. In a browser that cannot write to a folder it downloads the file instead.

Project file in a folder

An .aerion project file named after the project, written by itself without asking each time. Open it later with Open, like any project file.

  • Write the file on each save: tick it to write the file each time the project is saved. With saving on every change, the file is written at most once a minute.
  • Also write it every: Off, 5, 10, 15 or 30 minutes, while you are changing the project.

Where the file goes:

  • Desktop app: Documents\Aerion\Projects, or the folder you pick with Choose folder. Show folder opens it in File Explorer. Aerion writes only into that folder and never writes over a file it did not write itself: if another file has the same name, the project file is called, say, Smith house (2).aerion.
  • Chrome or Edge: Pick a folder once. The browser may ask again for permission after it restarts; press Save project file now to allow it.
  • Other browsers: the card says this works in the desktop app and in Chrome or Edge. Save project file now downloads the file.

The Save button in the top bar and Save file on the Projects page still open the normal save window, as before.

Backup copies

Earlier versions of each project, kept on this computer.

  • Keep: Off, or the last 5, 10 or 20 versions of each project.
  • While working, every: 5, 10, 15 or 30 minutes.

A backup is taken each time the project is saved (with saving on a timer or off) and every few minutes while you work. The list shows each backup's time and size (backups taken between saves say "while working"):

  • Restore opens the backup as a new project, named with the backup's date and time. The original project is not changed.
  • Download saves the backup as a project file.

Limits

  • The recovery copy and the backups are kept in this browser's (or the desktop app's) own storage on this computer. Clearing the browser's site data removes them. Keep project files for jobs that matter.
  • A backup that is the same as the one before is not kept twice.
  • Settings are per computer. A project file does not carry them.
